# Hash Rosin, Pressed

> **This repo is free. My 2am dryback debugging is not.** If it saved you a crop, a weekend, or a nervous breakdown — [buy the rabbit a bag of nutes](https://github.com/sponsors/JakeTheRabbit). If it didn't, keep your money. I respect a tight nutrient budget.

A systems-thinking field guide for solventless hash rosin — the press as a coupled
**heat / pressure / time / screen** system acting on a material whose quality ceiling was
fixed upstream at harvest, in the wash, and in the dry.

**Live site:** https://jaketherabbit.github.io/hash-rosin-pressing-levers/

## What's inside

- Starting setpoints by input material — flower, dry sift/kief, fresh-frozen hash, dried/cured hash
- The full farm-to-dab pipeline at a glance, with the cold-chain steps marked
- The press as four coupled balances (heat, pressure/flow, moisture, purity)
- A complete lever inventory — upstream, press, and finishing levers
- Main lever interaction matrix — direction of effect for every adjustment
- Symptom-to-parameter matrix — read a result, find the lever that moved too far
- Worked example: what raising plate temperature +6 °C actually cascades into
- Stage deep-dives — harvest, freeze/dry, ice-water wash, dry sift, freeze-dry, grading, pre-press, press, collection
- Equipment-specific effect tables (press classes, plates, bags, wash & freeze-dry gear)
- Input / trichome interaction matrix — head size and grade → micron, temp, ramp, product
- Post-press product paths — badder, sauce, diamonds & sauce, carts, hash holes
- Eight common failure modes with root causes and fixes
- Practical control hierarchy and a minimal troubleshooting matrix
- The simplest mental model: the pressing chain in one sentence

Single self-contained HTML file. No external dependencies.
